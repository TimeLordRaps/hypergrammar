# Hyper-Grammar Prerequisites — Learning Path

This directory is the prerequisite track for understanding `hyper-grammar` from first principles.

## Read in this order

1. [`01_grammar_fundamentals.md`](./01_grammar_fundamentals.md)
   - Core terms: alphabets, symbols, productions, derivations, parse trees, ambiguity.
2. [`02_chomsky_hierarchy.md`](./02_chomsky_hierarchy.md)
   - Classical grammar classes (Type-3 to Type-0), machine intuition, and inclusion chain.
3. [`03_hyper_inversion.md`](./03_hyper_inversion.md)
   - How `hyper-grammar` reframes the classical ladder as loop cross-sections.

## Companion spec documents

- [`../../AGENTS.md`](../../AGENTS.md) — formal source of truth for symbols and closure claims.
- [`../../HUMANS.md`](../../HUMANS.md) — plain-language mirror.

## Suggested study workflow

1. Read the page.
2. Re-derive one example by hand.
3. Follow the links in `03_hyper_inversion.md` back to the exact source of each claim.
4. If a definition appears inconsistent with `AGENTS.md`, log it in `TIME.md`.

## Scope

These docs are educational prerequisites. They are not replacements for the formal statements in [`../../AGENTS.md`](../../AGENTS.md).
